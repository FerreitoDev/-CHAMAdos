# Comandos

## Backend

### Desenvolvimento

npm run start:dev

### Testes

npm run test

### Build

npm run build

### Lint

npm run lint

## Prisma

### Gerar Prisma Client

npx prisma generate

### Criar migration

npx prisma migrate dev --name <nome>

### Abrir Prisma Studio

npx prisma studio

## Docker

### Iniciar serviços

docker compose up -d

### Parar serviços

docker compose down

### Ver containers

docker compose ps

### Ver logs

docker compose logs
