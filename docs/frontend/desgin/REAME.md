# Design System — CHAMAdos

Este diretório contém as definições visuais e decisões relacionadas ao design system do CHAMAdos.

## Objetivo

Estabelecer uma identidade visual consistente para toda a aplicação antes da implementação das telas e funcionalidades.

## Princípios

- Aparência corporativa e profissional.
- Interface limpa e objetiva.
- Uso moderado da identidade visual baseada no conceito de fogo.
- Cores semânticas para representar estados do sistema.
- Componentes reutilizáveis.
- Consistência visual entre telas.
