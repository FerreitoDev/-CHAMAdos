# AD-003 — Stack Visual do Frontend

**Decisão:** O frontend do CHAMAdos utilizará Tailwind CSS como ferramenta de estilização, shadcn/ui como base de componentes e Lucide Icons como biblioteca de ícones.

## Motivos

- Permitir a construção de uma interface com aparência corporativa e profissional.
- Manter consistência visual entre as diferentes áreas do sistema.
- Evitar dependência de uma identidade visual rígida de uma biblioteca de componentes.
- Permitir personalização dos componentes conforme a identidade do CHAMAdos.
- Facilitar a criação de interfaces responsivas.
- Reduzir a necessidade de desenvolver componentes de interface básicos do zero.
- Utilizar uma solução amplamente adequada para aplicações SaaS e sistemas administrativos.

## Responsabilidades

### Tailwind CSS

Será utilizado para:

- estilização;
- layout;
- espaçamento;
- responsividade;
- tipografia;
- estados visuais;
- tokens visuais definidos pelo projeto.

### shadcn/ui

Será utilizado como base para componentes de interface reutilizáveis, como:

- botões;
- inputs;
- dialogs;
- dropdowns;
- tabelas;
- formulários;
- componentes de navegação.

Os componentes serão incorporados ao código do projeto e poderão ser adaptados conforme as necessidades do CHAMAdos.

### Lucide Icons

Será utilizado como biblioteca padrão de ícones da aplicação.

## Observação

A utilização dessas ferramentas não determina antecipadamente a identidade visual final do CHAMAdos.

A paleta de cores, tipografia, espaçamentos, bordas e demais elementos do design system serão definidos durante a construção da fundação visual.
